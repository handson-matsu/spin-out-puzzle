# Spin-Out Puzzle — スライド機構版

**Macでは、このフォルダの `index.html` をダブルクリックしてください。** サーバー不要。`engine.js`、`mechanics.js`、`app.js`、`access-counter.js`、`style.css` も同じフォルダに置いてください。パズル自体は外部ライブラリ・通信・ストレージに依存しません。ページ読込時のみ、既存教材と共通のGASへアクセスを記録します。Git操作は実施していません。

## 操作

1. 緑色の持ち手または台の板を左右にドラッグする。離すと、通れる範囲で最寄りの整数目盛へスナップする。
2. 上レールの丸い窓へ円盤の中心を合わせ、円盤をクリック／タップする。
3. 接触して止まったときは赤い輪郭と×印を見る。円盤の凸部・凹部とレールが実際に接触している場所を示す。
4. 台を左へ引き抜くとクリア。

円盤は**左から1、2…**。初期の凸部は下向き。通常のクリックは下↔右を往復します。「↶90°」「↷90°」は選択円盤の別方向も試せます。最初の円盤だけは直線辺があります。ケース外の円盤にも恣意的な回転禁止を置いていません。

スマホ・iPadは持ち手を指でドラッグ。盤面の余白は横スクロールできます。持ち手の上にある左右の小さな矢印ボタンは1回につき1目盛。44pxの押せる領域を持ち、ドラッグと併用できます。持ち手にフォーカスした左右矢印キーでも操作できます。Undoは回転だけでなくスライドも1操作ずつ戻します。

## 実物に基づく仕組み

参照資料：William Keister, [US3637215A](https://patents.google.com/patent/US3637215A/en) のFig.1〜4と詳細説明。円盤を載せた台、上レールの回転窓、下レールのストッパー、先頭円盤の直線辺を確認しました。図面は向きを揃えて目視確認しています。

旧版は回転可否を二進状態から直接決定していました。改修版は `mechanics.js` に円盤・レール・台の位置を定義し、接触検査で操作を止めます。描画も同じ半径・円弧・位置を参照します。緑の操作可能マーカーは廃止しました。

このモデルは**特許の機構を正規化した2D教材**です。特許に実寸がないため、市販品の寸法や製造上の遊びを再現したものではありません。寸法・検査精度と未検証部分は [MECHANISM.md](MECHANISM.md) を参照してください。

## 手数・ヒント・自動再生

- 円盤1枚の90度回転＝1回。半回転は2回。スライドは回転数に含めない。
- 画面の数値欄は「手数」だけ。「最少回転」「引出し」の常時表示は削除。内部の0-1 BFSとヒントは維持。
- ヒント・手本の全スライド／回転も接触検査を通す。ヒント表示だけでは手数は増えない。
- 目盛位置の探索における結果は、3〜8枚で **5、10、21、42、54、55回**。連続位置全体や実製品に対する最短性は未証明。
- 7枚の54回はケース外の追加回転を使う。85回へ合わせるための非物理的な制限は置いていない。
- 探索上限20,000ノードを超えた場合のみ、可能なら正規2向きの手本へフォールバックし、ヒントに明記する。
- 探究欄の **5、10、21、42、85、170回** は下／右の正規2向きだけの参考値。実機構全体の最短値とは区別する。

不要な初期計算待ちはなく、最初から操作できます。再生は停止・速度調整可能。クリアは全ての円盤が横になった時点ではなく、台の移動アニメーションが終わり、全体がケースから抜けた時点で表示します。中央の「クリア！」、短い達成アニメーション、空のケースの表示が出ます。「最初から」で再挑戦できます。

旧表示のクリア後の54は、残りではなく初期状態の計算値を表示し続けていたものです。クリア後の探索結果は0回・経路なしであることをテストしています。

台、円盤番号、追従する表示範囲、持ち手付近のボタンは同じフレームの位置から描画します。スライドのCSS transitionと瞬間的なカメラ切替の競合を解消しました。最終位置では台全体と空のケースが両方見えます。

## ローカル起動とテスト

ES Modulesを使わず、通常のscriptタグでengine.js→mechanics.js→app.jsの順にゲームを起動し、その後access-counter.jsを読み込みます。CSSも相対パスです。アクセス記録のfetchはゲームから独立し、file://やオフラインで失敗してもゲームを継続できます。GitHub Pagesのサブパスでも読込可能な構成です。

```sh
node --test tests/*.test.js
```

Node.js 18以降を推奨。遊ぶだけならNode不要。

テスト結果と確認限界は [VERIFICATION.md](VERIFICATION.md) を参照してください。ブラウザ操作ツールはfile://を許可しないため、改修後の直接起動の目視確認は未実施です。セキュリティ制限を回避する操作は行っていません。
